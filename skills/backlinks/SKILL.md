# Backlinks

## Steps

1. `analyze_competitors` `operation: "list"` to choose the competitor(s) to compare against — pick the one ranking for the user's most valuable keywords.
2. `analyze_competitors` `operation: "backlink_gap"` with that competitor's domain. Paid plans only; if the tool returns an upgrade link, pass it on.
3. Sort the gap by authority and relevance. Group by type: industry publications, directories and listings, resource pages, blogs and podcasts, partners and integrations.
4. For each group recommend the tactic: listing (submit), resource page (pitch the best page), editorial (needs a linkable asset → `statistics-page`), broken or outdated links (→ `link-building-playbooks`).

## Managed backlinks

Workspaces with a SEOsorted backlink package get directory submissions done for them; progress and domain-authority trend are on the Backlinks page of the dashboard.

## Guardrails

No paid links, link farms or PBNs — they put the site at risk. Recommend links a real editor would give.
